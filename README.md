# 火鍋の店 (Hot-Pot Game)

火鍋店を経営する2D接客ゲームです。仕入れ（Daily Market）で食材を買い、お客さんの注文どおりにスープ・麺・具を選んで提供し、会計（現金のおつり／QR）まで行います。HTML / CSS / JavaScript のみで動作し、進行状況は localStorage と Supabase（匿名ログイン）に保存されます。

## 特徴

- **仕入れ → 営業の1日サイクル**：毎日食材を買ってから開店。仕入れすぎると資金不足、少なすぎると食材切れで早じまい。
- **制限時間つきの接客**：スープ・麺・具を注文どおりに選ぶ。間違えると我慢時間が減り、時間切れで罰金。
- **リアルな会計**：現金のおつりを紙幣・硬貨で選ぶ（おつりが出せない時はQR）。
- **食材が少しずつ解放**：日数が進むと新しい食材が増え、注文も複雑になる。
- **3言語対応（ベトナム語・日本語・英語）**：ボタン1つで切り替え。
- **登録不要のクラウドセーブ**：匿名ログインで進行状況を自動保存。

## UXフロー

### コア（1日の流れ）

スタート画面 → 1日の始まり → 仕入れ → 開店 → 接客 → 会計 → 1日の終了 → 翌日の仕入れ、の繰り返しです。

![UXフロー：コア](docs/ux/ux-flow-core.png)

### メタ（スタート画面のサブ画面）

あそびかた、設定、レシピメモ、月別の売上、やり直す確認です。

![UXフロー：メタ](docs/ux/ux-flow-meta.png)

### メタ2（ゲーム中のサブ画面）

一時停止、ゲーム中の設定、やり直す、早めに閉店です。

![UXフロー：メタ2](docs/ux/ux-flow-meta2.png)
